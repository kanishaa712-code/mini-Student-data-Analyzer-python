# 🎓 Student Performance Management System

A beginner-friendly Python project to manage and analyze student scores.

## 📌 About the Project

This project stores student information using a list of dictionaries and analyzes their scores.

It can:

- 🔎 Search for a student by name
- 📊 Display the student's score
- 🏆 Categorize students based on their scores
- 📝 Assign grades
- 📈 Store and process student scores

## 🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Conditional Statements
- User Input

## 📚 Concepts Practiced

- List of Dictionaries
- `for` loops
- `if / elif / else`
- `.append()`
- `input()`
- Dictionary access
- Searching data
- Basic data processing
